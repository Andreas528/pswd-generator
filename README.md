# Password Generator

A simple Python CLI tool that generates secure random passwords using Python's built-in `secrets` module.

## Features

- Choose your password length.
- Include or exclude lowercase letters.
- Include or exclude uppercase letters.
- Include or exclude numbers.
- Include or exclude symbols.
- Input validation to prevent invalid selections.
- Cryptographically secure random password generation.

## Requirements

- Python 3.12 or newer.

No external packages required.

## Usage

Clone the repository:

```bash
git clone git@github.com:Andreas528/pswd-generator.git
cd pswd-generator
```

Run the program:

```bash
python main.py
```

Follow the prompts to configure and generate your password.
